按下「Sign in」就是架構圖裡 OIDC 的步驟 1。接著會發生：

  1. Client App 回 302，把瀏覽器導向 Keycloak（步驟 2 → 3）
  2. 你在 Keycloak 的登入頁輸入帳號密碼，Keycloak 去 OpenLDAP 驗證（步驟 4）
  3. Keycloak 把瀏覽器帶著 code + state 導回來（步驟 5 → 6）
  4. Client App 驗證 state、用 code（+ PKCE code_verifier）換 token（步驟 7 → 9）
  5. Client App 驗證 id_token 後建立 session，你就登入了（步驟 10）
